## High-Signal Findings

**1. Dynamic Workflows / Ultracode (Anthropic research preview, May 28 2026)**
Claude writes a JavaScript orchestration script on the fly; a separate runtime executes it while your chat stays free. Can spawn 10–100+ parallel subagents. Triggered by typing "workflow" in a prompt or setting `/effort ultracode`. Available on all paid plans (research preview).
Source: claude.com/blog, x.com/@trq212, x.com/@minchoi, x.com/@gregisenberg

**2. Plan Mode (/plan command, formalized Jan 2026)**
Shift+Tab cycles: Default → Auto-Accept → Plan Mode. In Plan Mode, write tools are structurally blocked — Claude can only read and plan. `/plan` is a slash command added Jan 2026. Practitioners recommend it for any task touching 3+ files, schema changes, or security-sensitive code.
Source: blink.new/blog, vibecodingacademy.ai, getaiperks.com, theaiarchitects.com

**3. Explore → Plan → Code as a formal 3-step workflow**
Pushing codebase exploration to a read-only isolated subagent prevents "dead-end contamination" — failed greps and wrong-file reads accumulating in the main context window. The main session stays clean for actual coding.
Source: tembo.io/blog, smartscope.blog, x.com/@bhaidar

**4. Stop hook exit-code-2 pattern**
A Stop hook that runs your test suite and exits 2 forces Claude to keep iterating without human input until tests pass. PreToolUse hooks that exit 2 block the tool call entirely — use for safety gates (blocking `rm -rf`, `DROP TABLE`).
Source: claudefa.st hooks guide, pixelmojo.io CI/CD patterns, blakecrosley.com

**5. HTTP hooks (Feb 2026)**
Hooks can now POST to an HTTP endpoint instead of only running shell commands — useful for logging to dashboards, triggering external automation, or integrating with observability tools.
Source: morphllm.com, aiproductivity.ai

**6. Rewind checkpoints (Oct 2025 — established feature)**
Claude auto-saves code state before each edit. You can rewind to any prior state — enables fearless experimentation without worrying about git stash or branch management.
Source: x.com/@bhaidar, general search results

**7. 5-parallel-session power user workflow**
Run 5 Claude sessions in numbered terminal tabs; use system notifications when any tab needs input. Opus is slower per turn but requires less steering, so faster overall for complex tasks.
Source: x.com/@aakashgupta (summarizing Claude Code creator's workflow)

## Human-Side Practices (for Casey)

1. **Enter Plan Mode before large tasks**: Type `/plan` (or Shift+Tab twice) before any task touching 3+ files. Review the plan — add files Claude missed, remove files it shouldn't touch — then approve. This is the highest-leverage human intervention before execution starts.

2. **Wire up a Stop hook for tests**: In a project's `.claude/settings.json`, add a Stop hook that runs the test suite and exits 2 on failure. Claude keeps iterating until tests pass without needing copy-pasted failure output.
   ```json
   {
     "hooks": {
       "Stop": [{ "hooks": [{ "type": "command", "command": "npm test || exit 2" }] }]
     }
   }
   ```

3. **Try Ultracode on a genuinely complex task**: Set `/effort ultracode` (requires Opus model), hand Claude a well-scoped multi-file task with "create a workflow" in the prompt, and watch it orchestrate parallel subagents. Currently research preview — good time to experiment.
